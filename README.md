# PP-degrading-enzyme-discovery-honours-project-2026
Hello everyone! The project uses a deep learning-assisted pipeline to identify promiscious iron-dependent enzymes that may be compatible with polypropylene binding, and hence cause oxidative attack on the polypropylene ligand based on the functionality of HIS1 discovered by Tan et al in 2024. The project particularly explores the Fe(II)/2-oxoglutarate and heme protein search spaces, obtaining datasets from UniProt. The overall aim is to expand the scope of polypropylene degrading enzymes; using this as the initial high-throughput hypotheses-generating methodology and experimental test the shortlisted candidates. 


This GitHub repo presents the work that I have undertaken during my Biotechnology honours project. Attached here are all the main scripts that I designed for this pipeline. Scripts were run using python and some in linux (mentioned if so). I have presented the scripts from the Fe(II)/2-oxoglutarate group perspective, some additional heme-associated scripts were added to provide context if anything significantly changed in the methodology. Some additional scripts, such as dataset used and figure building scripts, are not included due to file size restrictions and to reduce complexity of pipeline presentation. If you would like to know more, please feel free to comment and I will get back to you. 

Flow of the pipeline: 

1. Plausibility -- Clustering down datasets
2. Compatibility -- Structural preduction and molecular docking
3. Stability -- enzyme-PP complex dynamic interaction
